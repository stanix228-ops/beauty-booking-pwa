# CLONE-IN-6-MINUTES.md — Клонирование приложения под новую студию за 6 минут

Благодаря конфигурационному конвейеру запуск новой студии маникюра не требует изменения исходного кода `src/`.
Все настройки, палитра, услуги, мастера и расписания задаются через один файл `business.json`.

---

## Пошаговый сценарий (6 минут)

### Минута 1: Создание каркаса новой студии
Выполните команду генерации каркаса (укажите slug и название студии):
```bash
npm run tenant:new velvet-nails "Velvet Nails & Spa"
```
Скрипт создаст директорию: `tenants/velvet-nails/` со структурой:
- `tenants/velvet-nails/business.json` (готовый валидный JSON со сгенерированными UUID)
- `tenants/velvet-nails/assets/` (каталог для фото)

---

### Минуты 2–3: Настройка параметров и брендинга
Откройте `tenants/velvet-nails/business.json` и настройте параметры:
1. **Цветовая палитра студии:**
   ```json
   "theme": {
     "accentColor": "#C084FC",  // Ваш фирменный акцентный цвет (HEX)
     "bgColor": "#0A0A0F",      // Глубокий темный фон
     "cardBgColor": "#13131A",  // Цвет карточек
     "textColor": "#F3F4F6",
     "mutedColor": "#9CA3AF"
   }
   ```
2. **Адрес, телефон и график работы:**
   - Заполните `address`, `phone`, `city` и массив `businessHours`.
3. **Услуги и цены:**
   - Отредактируйте массив `services` (название, цена, длительность в минутах, буфер).
   - При необходимости добавьте дополнительные опции в массив `options` (снятие, укрепление, френч).
4. **Мастера:**
   - Заполните имена, специализации и привяжите `serviceIds`.

---

### Минута 4: Валидация конфигурации
Запустите проверку корректности файла:
```bash
npm run tenant:validate velvet-nails
```
Zod проверит форматы цветов, корректность расписаний и целостность внешних ключей.

---

### Минута 5: Публикация и генерация SQL/PWA
Запустите конвейер публикации:
```bash
npm run tenant:publish
```
Конвейер автоматически:
1. Создаст SQL-скрипт `supabase/generated/publish_velvet-nails.sql`.
2. Сгенерирует индивидуальный Web App Manifest `public/tenants/velvet-nails/manifest.webmanifest`.
3. Зарегистрирует студию в статической сборке `src/data/tenants.ts`.

---

### Минута 6: Верификация и запуск
1. Запустите автоматическую проверку изоляции:
   ```bash
   npm run tenant:verify
   ```
2. Откройте приложение:
   - Клиентская страница записи: `http://localhost:5173/s/velvet-nails/`
   - Мобильный кабинет владельца: `http://localhost:5173/s/velvet-nails/owner/`

---

## Главный архитектурный результат:
- Новая студия получает уникальный URL и персональный дизайн.
- Ранее запущенные студии (`lumi-nail-studio`, `aura-nail-bar`) продолжают работать без сбоев.
- Ни одна строчка в `src/` не была изменена вручную!
- Существующие записи и клиенты в базе данных остаются на 100% в сохранности.
